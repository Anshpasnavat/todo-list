# To-Do List

A simple To-Do List web application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Prevent empty tasks
- Delete tasks
- Clear input after adding a task
- Simple and clean UI

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

1. Enter a task in the input field.
2. Click the **Add** button.
3. The task appears in the list with a **Delete** button.
4. Click **Delete** to remove the task.
